## Historias de usuario
#### Usuarios Primarios
- Como **dueño de un establecimiento**, quiero elegir y cambiar el tipo de recompesas que ofrezco, para ajustarlas a las necesidades del negocio.

- Como **dueño de un establecimiento**, quiero definir reglas de acumulación (por ejemplo, 1 punto por cada $10), para controlar cuánto cuesta mi programa de lealtad.

- Como **cajero**, quiero tener una clave de acceso, para poder administrar las compras y los canjes de los clientes.


#### Usuarios secundarios
- Como **cliente**, quiero consultar mi nivel y puntos acumulados, para conocer mis recompesas disponibles.

- Como **cliente**, quiero conocer que negocios adaptaron este sistema, para saber a cuales puedo ir.

#### Usuario de Soporte
- Como **soporte técnico**, quiero revertir un canje fallido o duplicado, para devolver los puntos al consumidor.

- Como **soporte técnico**, quiero suspender temporalmente una cuenta con actividad sospechosa, para prevenir fraudes mientras se investiga.
