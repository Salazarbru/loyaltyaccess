 # Diagramas de Casos de Uso

Los diagramas de casos de uso representan las principales interacciones entre los usuarios y las funciones de LoyaltyAccess.

## Caso de uso: Dueño del negocio

![Diagrama](https://i.ibb.co/TDtwmSJv/Diagrama-due-o-del-negocio.png)

Este diagrama representa las funciones disponibles para el dueño del negocio, como la configuración del programa de lealtad, la gestión de clientes, cajeros, premios y promociones.

## Caso de uso: Cajero

![Caso de uso - Cajero](https://i.ibb.co/PsBYNGF1/Diagrama-cajero.png)

Este diagrama muestra las operaciones realizadas por el cajero, principalmente la identificación de clientes, el registro de compras o visitas y el canje de premios.

## Caso de uso: Cliente

![Caso de uso - Cliente](https://i.ibb.co/ynfRYd00/Diagrama-cliente.png)

Este diagrama representa la interacción del cliente con su tarjeta digital, permitiéndole consultar sus puntos o sellos, premios disponibles y mostrar su código QR.

## Caso de uso: Administrador de la plataforma

![Caso de uso - Administrador](https://i.ibb.co/v6LzZk3G/Diagrama-administrador-de-plataforma.png)

Este diagrama muestra las funciones del administrador de LoyaltyAccess, como la gestión de negocios registrados y de las plantillas de programas de lealtad.
