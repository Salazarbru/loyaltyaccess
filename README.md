## 🎯 Objetivo
Queremos poder ofrecer una alternativa a los emprendedores para que puedan tener un mayor alcance de clientes de tal manera que tengan un sistema atractivo de lealdad

## 💡 Descripción
El proyecto busca implementar una solución orientada a que los negocios y emprendedores optimicen la retención y captación de clientes mediante una experiencia de lealtad atractiva, accesible y funcional.
